- JSON and Kyero inventories share portal selection and contact eligibility; complete server reads are paged and fail closed. XML/index return 503 with Retry-After rather than partial inventory; unrenderable Kyero data also fails the entire document. Why: an incomplete inventory must never become a withdrawal signal.
- Index authentication uses portal-scoped hash rows and explicit legacy revocation tombstones; managed agency signatures use the digest while legacy signatures keep the original secret, with atomic five-minute touches. Why: rotation must not silently invalidate existing XML consumers or require plaintext key storage.
- Visit event receipts are durable and unique by organization, authenticated portal identity and event ID (site tokens use token ID); the service-only RPC claims and increments in one transaction, while absent event IDs keep the original increment path. Why: retries and rotated portal keys must not count twice or mix agencies.
